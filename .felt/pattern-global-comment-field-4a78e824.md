close-reason: 'When building annotation/review/feedback UIs, global comment fields should be visible in the main view, not hidden behind a secondary action. User expects to compose overall feedback while reviewing individual annotations. Hiding it in the worker picker modal created friction — user had to click ''Send to Worker'' just to see the comment field. Fix: moved global comment textarea to bottom of annotations panel, always visible when annotations exist.'
